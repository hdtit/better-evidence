# Better Evidence

Erfassen Sie komplette Webseiten als überlappende Screenshots, als PDF und als MHTML-Quelldatei. 
Better Evidence bündelt die resultierenden Dateien und Metadaten in einem ZIP-Archiv und erstellt eine Timestamp-Response-Datei. 
Eine externe Timestamp-Authority bestätigt den Zeitstempel und die Integrität des ZIP-Archivs. 
Ihre Daten werden nicht an die Timestamp-Authority übermittelt. 
Alles in einem Arbeitsablauf.

Sie können außerdem für jede beliebige Datei Hash-Werte und Timestamp-Response-Dateien mit Zeitstempel erstellen und überprüfen.
